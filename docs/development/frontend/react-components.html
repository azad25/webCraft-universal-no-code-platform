React Components

Building reusable, performant React components for WebCraft

Component Architecture

WebCraft follows a component-based architecture with clear separation of concerns. Components are organized by functionality and reusability.

Component Hierarchy

  • Atoms: Basic building blocks (Button, Input, Text)
  • Molecules: Combinations of atoms (Form Field, Search Bar)
  • Organisms: Complex components (Header, Sidebar, Widget)
  • Templates: Page-level layouts (Dashboard, Editor)
  • Pages: Full pages with specific content

Component Structure

Widget Components

Widget components are the core building blocks of the WebCraft editor. They need to be draggable, configurable, and renderable.

Base Widget Interface

// types/widgets.ts
export interface WidgetProps {
  id: string
  type: string
  position: { x: number; y: number }
  size: { width: number; height: number }
  properties: Record
  styles?: React.CSSProperties
  isSelected?: boolean
  isDragging?: boolean
  onSelect?: (id: string) => void
  onUpdate?: (id: string, updates: Partial) => void
  onDelete?: (id: string) => void
}

export interface WidgetDefinition {
  type: string
  name: string
  icon: string
  category: 'basic' | 'layout' | 'form' | 'media' | 'advanced'
  defaultProps: Partial
  render: React.FC
  propertiesPanel: React.FC<{ widget: WidgetProps; onUpdate: (updates: any) => void }>
}
