Integrate External APIs

Learn how to integrate external APIs into your WebCraft widgets and applications

Overview

This tutorial will guide you through integrating external APIs into WebCraft widgets. We'll build a weather widget that fetches data from a weather API and displays it beautifully in your WebCraft pages.

What You'll Learn

  • Setting up API integrations in WebCraft
  • Creating secure API connections
  • Handling API responses and errors
  • Building responsive widgets with external data
  • Implementing caching for better performance
  • Adding loading states and error handling

Prerequisites

  • Basic knowledge of TypeScript/JavaScript
  • Understanding of React components
  • API key from OpenWeatherMap (free tier available)
  • Completed the Create Custom Widget tutorial

Setting Up the API Integration

1. Get API Credentials

First, sign up for a free API key from OpenWeatherMap:

  1. Go to OpenWeatherMap API
  2. Sign up for a free account
  3. Get your API key from the dashboard
  4. Note down your API key (we'll use it in the configuration)

3. Create API Service

Build a service to handle API requests with proper error handling and caching:

// widgets/weather/api/weather.service.ts
import { WeatherAPIConfig, WeatherData, WeatherError, weatherEndpoints } from './weather.config';

class WeatherAPIService {
  private config: WeatherAPIConfig;
  private cache: Map = new Map();
  private requestQueue: Array<() => Promise> = [];
  private isProcessing = false;

  constructor(config: WeatherAPIConfig) {
    this.config = config;
  }

  async getCurrentWeather(city: string): Promise {
    const cacheKey = `weather_${city.toLowerCase()}`;
    
    // Check cache first
    const cached = this.getFromCache(cacheKey);
    if (cached) {
      return cached;
    }

    try {
      const response = await this.makeRequest(
        `${this.config.baseURL}${weatherEndpoints.currentWeather}`,
        {
          q: city,
          appid: this.config.apiKey,
          units: 'metric'
        }
      );

      const weatherData = this.transformWeatherResponse(response);
      this.setCache(cacheKey, weatherData);
      
      return weatherData;
    } catch (error) {
      throw this.handleAPIError(error);
    }
  }

  async getWeatherByCoords(lat: number, lon: number): Promise {
    const cacheKey = `weather_${lat}_${lon}`;
    
    // Check cache first
    const cached = this.getFromCache(cacheKey);
    if (cached) {
      return cached;
    }

    try {
      const response = await this.makeRequest(
        `${this.config.baseURL}${weatherEndpoints.currentWeather}`,
        {
          lat,
          lon,
          appid: this.config.apiKey,
          units: 'metric'
        }
      );

      const weatherData = this.transformWeatherResponse(response);
      this.setCache(cacheKey, weatherData);
      
      return weatherData;
    } catch (error) {
      throw this.handleAPIError(error);
    }
  }

  private async makeRequest(url: string, params: Record): Promise {
    const queryString = new URLSearchParams(params).toString();
    const fullUrl = `${url}?${queryString}`;

    const controller = new AbortController();
    const timeoutId = setTimeout(() => controller.abort(), this.config.timeout);

    try {
      const response = await fetch(fullUrl, {
        method: 'GET',
        signal: controller.signal,
        headers: {
          'Accept': 'application/json',
        }
      });

      clearTimeout(timeoutId);

      if (!response.ok) {
        throw new Error(`HTTP ${response.status}: ${response.statusText}`);
      }

      return await response.json();
    } catch (error) {
      clearTimeout(timeoutId);
      throw error;
    }
  }

  private transformWeatherResponse(response: any): WeatherData {
    return {
      location: {
        name: response.name,
        country: response.sys.country,
        lat: response.coord.lat,
        lon: response.coord.lon
      },
      current: {
        temp: Math.round(response.main.temp),
        feels_like: Math.round(response.main.feels_like),
        humidity: response.main.humidity,
        pressure: response.main.pressure,
        wind_speed: response.wind.speed,
        wind_direction: response.wind.deg || 0,
        weather: response.weather.map((w: any) => ({
          id: w.id,
          main: w.main,
          description: w.description,
          icon: w.icon
        }))
      },
      timestamp: Date.now()
    };
  }

  private getFromCache(cacheKey: string): WeatherData | null {
    const cached = this.cache.get(cacheKey);
    
    if (cached && (Date.now() - cached.timestamp) < this.config.cacheTTL) {
      return cached.data;
    }
    
    // Remove expired cache entry
    if (cached) {
      this.cache.delete(cacheKey);
    }
    
    return null;
  }

  private setCache(cacheKey: string, data: WeatherData): void {
    this.cache.set(cacheKey, {
      data,
      timestamp: Date.now()
    });
  }

  private handleAPIError(error: any): WeatherError {
    if (error.name === 'AbortError') {
      return {
        code: 'TIMEOUT',
        message: 'Weather API request timed out'
      };
    }
    
    if (error.message?.includes('401')) {
      return {
        code: 'INVALID_API_KEY',
        message: 'Invalid weather API key'
      };
    }
    
    if (error.message?.includes('404')) {
      return {
        code: 'CITY_NOT_FOUND',
        message: 'City not found'
      };
    }
    
    return {
      code: 'API_ERROR',
      message: 'Failed to fetch weather data',
      details: error.message
    };
  }

  clearCache(): void {
    this.cache.clear();
  }
}

export const weatherAPIService = new WeatherAPIService(defaultWeatherConfig);

// widgets/weather/hooks/useGeolocation.ts
import { useState, useEffect } from 'react';

interface GeolocationState {
  latitude: number | null;
  longitude: number | null;
  error: string | null;
  loading: boolean;
}

export const useGeolocation = (): GeolocationState => {
  const [state, setState] = useState({
    latitude: null,
    longitude: null,
    error: null,
    loading: true
  });

  useEffect(() => {
    if (!navigator.geolocation) {
      setState(prev => ({
        ...prev,
        loading: false,
        error: 'Geolocation is not supported by this browser'
      }));
      return;
    }

    const successHandler = (position: GeolocationPosition) => {
      setState({
        latitude: position.coords.latitude,
        longitude: position.coords.longitude,
        error: null,
        loading: false
      });
    };

    const errorHandler = (error: GeolocationPositionError) => {
      setState({
        latitude: null,
        longitude: null,
        error: error.message,
        loading: false
      });
    };

    const options: PositionOptions = {
      enableHighAccuracy: true,
      timeout: 10000,
      maximumAge: 300000 // 5 minutes
    };

    navigator.geolocation.getCurrentPosition(successHandler, errorHandler, options);
  }, []);

  return state;
};

class WeatherForecastService {
  async getForecast(lat: number, lon: number): Promise {
    try {
      const response = await fetch(
        `${defaultWeatherConfig.baseURL}/onecall?lat=${lat}&lon=${lon}&appid=${defaultWeatherConfig.apiKey}&units=metric`
      );
      
      if (!response.ok) {
        throw new Error(`HTTP ${response.status}`);
      }
      
      const data = await response.json();
      
      return {
        daily: data.daily.slice(0, 7).map((day: any) => ({
          date: new Date(day.dt * 1000).toLocaleDateString(),
          temp: {
            min: Math.round(day.temp.min),
            max: Math.round(day.temp.max)
          },
          weather: {
            main: day.weather[0].main,
            description: day.weather[0].description,
            icon: day.weather[0].icon
          }
        })),
        hourly: data.hourly.slice(0, 24).map((hour: any) => ({
          time: new Date(hour.dt * 1000).toLocaleTimeString([], { hour: '2-digit', minute: '2-digit' }),
          temp: Math.round(hour.temp),
          weather: {
            main: hour.weather[0].main,
            icon: hour.weather[0].icon
          }
        }))
      };
    } catch (error) {
      throw new Error('Failed to fetch forecast data');
    }
  }
}

export const weatherForecastService = new WeatherForecastService();

3. Deployment Considerations

  • API Rate Limits: Implement proper rate limiting to avoid exceeding API quotas
  • Security: Never expose sensitive API keys in client-side code
  • Caching: Use Redis or similar for distributed caching in production
  • Error Monitoring: Implement error tracking (e.g., Sentry) for production issues
  • Performance: Consider using a proxy server for API requests to improve performance
  • Fallbacks: Implement fallback data sources or cached data for reliability
