🎯 Link Types Supported

1. Page Links

Navigate to internal pages

{ type: 'page', target: 'about', label: 'About Us Page' } // Result: Navigates to /about
PAGE

Example: "Learn More" text → About page

2. Section Links

Scroll to page sections

{ type: 'section', target: '#hero', label: 'Go to Hero Section' } // Result: Smooth scrolls to #hero
SECTION

Example: Feature image → Hero section

3. Data Links

Dynamic content routing

{ type: 'data', target: 'products', parameters: { id: '123' } } // Result: Navigates to /data/products/123
DATA

Example: Product card → Product details

4. Custom Routes

Complex routing patterns

{ type: 'custom', target: '/products/[id]/reviews', parameters: { id: '123' } } // Result: Navigates to /products/123/reviews
CUSTOM

Example: Review button → Product reviews

5. External Links

External URLs and protocols

{ type: 'external', target: 'https://example.com', openInNewTab: true } // Result: Opens external site in new tab
EXTERNAL

Example: Partner logo → Partner website

6. Action Links

JavaScript actions

{ type: 'action', target: 'scroll-to-top', parameters: { behavior: 'smooth' } } // Result: Executes scroll action
ACTION

Example: Arrow icon → Scroll to top

🎯 User Experience Flow

Making Any Element Clickable

  1. Select any widget (text, image, card, hero, etc.)
  2. Widget toolbar appears automatically
  3. Click link button in Content tab
  4. Link manager opens with all options
  5. Choose link type (Page, Section, Data, Custom, External, Action)
  6. Configure target and parameters
  7. Apply link → Element becomes interactive
  8. Visual indicator shows element is linked
