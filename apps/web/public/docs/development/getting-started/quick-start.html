Quick Start Guide

Get WebCraft up and running in minutes

Prerequisites

Before you begin, ensure you have the following installed:

  • Docker & Docker Compose (Recommended) - Version 20.10+
  • Node.js 18+ (for local frontend development)
  • Python 3.11+ (for local backend development)
  • PostgreSQL 15+ (if running locally without Docker)
  • Redis 7+ (if running locally without Docker)

Option 1: Automated Setup Script (Recommended)

WebCraft includes an automated setup script that handles everything for you. This is the fastest way to get started.

Using the Setup Script

# Make the script executable
chmod +x setup.sh

# Run the setup script
./setup.sh

The script will:

  • Check system requirements (Docker, memory, disk space)
  • Offer three setup modes:
    • Quick Setup - Docker-based setup (recommended)
    • Web Setup Wizard - Start services and use web UI
    • Development Setup - For local development
  • Generate environment configuration
  • Start all required services
  • Guide you to the web setup wizard
Tip: After running the script, you'll be directed to the web setup wizard at http://localhost:3000/setup to complete the configuration.

Option 2: Web Setup Wizard

If you prefer a graphical interface, you can use the web-based setup wizard. This is automatically available after starting the services.

Accessing the Setup Wizard

  1. Start the services using Docker Compose: 
    docker compose up -d
  2. Wait for services to start (about 30 seconds)
  3. Open your browser and navigate to: 
    http://localhost:3000/setup

Setup Wizard Steps

The wizard guides you through 7 steps:

  1. Welcome - Introduction to WebCraft
  2. System Check - Verifies Docker, memory, disk space, and ports
  3. Database Configuration - Configure PostgreSQL (Docker or external)
  4. Admin Account - Create your administrator account
  5. Email Configuration - Optional SMTP setup for emails
  6. Features - Enable analytics, AI features, and API keys
  7. Installation - Automated setup process with progress tracking
Note: The setup wizard automatically detects if you're running in Docker and adjusts the setup process accordingly.

Option 3: Manual Docker Setup

For more control, you can manually set up using Docker Compose.

Step 1: Clone the Repository

git clone https://github.com/azad25/webCraft-universal-no-code-platform.git
cd webcraft-platform

Step 2: Start All Services

docker compose up -d

This will start:

  • Frontend (Next.js) on http://localhost:3000
  • Backend API (FastAPI) on http://localhost:8000
  • PostgreSQL database on port 5434
  • Redis cache on port 6381
  • Kafka message broker on port 9092

Step 3: Access the Setup Wizard

On first launch, open your browser and navigate to:

http://localhost:3000/setup

The setup wizard will automatically detect your environment and guide you through the configuration process.

Step 4: Access the Application

After completing the setup wizard, you can access:

  • Dashboard: http://localhost:3000
  • API Documentation: http://localhost:8000/docs
  • API Health: http://localhost:8000/health

Option 4: Local Development Setup

For development, you can run services locally without Docker.

Step 1: Start Infrastructure Services

# Start only infrastructure (PostgreSQL, Redis, Kafka)
docker compose up -d postgres redis kafka zookeeper

Step 2: Setup Backend

cd apps/api

# Create virtual environment
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Set environment variables
export DATABASE_URL="postgresql://webcraft:password@localhost:5434/webcraft_db"
export REDIS_URL="redis://localhost:6381"
export JWT_SECRET_KEY="your-secret-key-here"
export SECRET_KEY="your-secret-key-here"

# Run database migrations
alembic upgrade head

# Start the API server
uvicorn main:app --reload --host 0.0.0.0 --port 8000

Step 3: Setup Frontend

cd apps/web

# Install dependencies
npm install

# Set environment variables
export NEXT_PUBLIC_API_URL=http://localhost:8000
export NEXT_PUBLIC_WS_URL=ws://localhost:8000

# Start development server
npm run dev

Verify Installation

Check that all services are running correctly:

Health Check

# Check API health
curl http://localhost:8000/health

# Expected response:
{
  "status": "healthy",
  "version": "2.0.0",
  "services": {
    "database": "connected",
    "redis": "connected",
    "kafka": "connected"
  }
}

Database Connection

# Connect to PostgreSQL
docker exec -it webcraft-postgres-1 psql -U webcraft -d webcraft_db

# Or using local PostgreSQL
psql -h localhost -p 5434 -U webcraft -d webcraft_db

Create Your First App

Once the setup is complete, create your first application:

Via Web Interface

  1. Log in to the dashboard at http://localhost:3000
  2. Click "Create New App"
  3. Choose a template or start from scratch
  4. Use the visual editor to build your app

Via API

# Get authentication token
TOKEN=$(curl -X POST http://localhost:8000/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"admin@example.com","password":"your-password"}' \
  | jq -r '.access_token')

# Create a new app
curl -X POST http://localhost:8000/api/v1/apps \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "My First App",
    "app_type": "website",
    "description": "A test application"
  }'

Troubleshooting

Port Already in Use

If ports 3000, 8000, 5434, or 6381 are already in use:

# Check what's using the port
lsof -i :3000  # macOS/Linux
netstat -ano | findstr :3000  # Windows

# Change ports in docker-compose.yml

Database Connection Issues

Ensure PostgreSQL is running and accessible:

# Check Docker container status
docker compose ps

# View logs
docker compose logs postgres

Frontend Build Errors

Clear Next.js cache and rebuild:

cd apps/web
rm -rf .next node_modules
npm install
npm run dev
