Installation Guide

Complete installation instructions for WebCraft platform

System Requirements

Server Requirements

  • CPU: 2+ cores (4+ recommended)
  • RAM: 4GB minimum (8GB+ recommended)
  • Storage: 20GB+ free space
  • OS: Linux, macOS, or Windows

Development Tools

  • Docker 20.10+ & Docker Compose
  • Node.js 18+ (LTS recommended)
  • Python 3.11+
  • Git 2.30+

Database

  • PostgreSQL 15+
  • Redis 7+
  • Kafka (optional, for real-time features)

Installation Methods

Method 1: Docker Compose (Recommended)

Best for quick setup and production-like environment.

Step 1: Install Docker

# macOS
brew install docker docker-compose

# Ubuntu/Debian
sudo apt-get update
sudo apt-get install docker.io docker-compose

# Windows
# Download Docker Desktop from docker.com

Step 2: Clone Repository

git clone https://github.com/azad25/webCraft-universal-no-code-platform.git
cd webcraft-platform

Step 3: Configure Environment

# Copy example environment file
cp .env.example .env

# Edit .env with your configuration
nano .env

Step 4: Start Services

# Start all services
docker compose up -d

# View logs
docker compose logs -f

# Check service status
docker compose ps

Method 2: Manual Installation

For development or custom deployments.

Backend Setup

cd apps/api

# Create virtual environment
python3 -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# Install dependencies
pip install --upgrade pip
pip install -r requirements.txt

# Setup database
createdb webcraft_db
alembic upgrade head

# Run migrations
alembic upgrade head

Frontend Setup

cd apps/web

# Install dependencies
npm install

# Build for production
npm run build

# Start production server
npm start

PostgreSQL Setup

Using Docker

# PostgreSQL is included in docker-compose.yml
# Default credentials:
# - Database: webcraft_db
# - User: webcraft
# - Password: password
# - Port: 5434

Manual PostgreSQL Installation

# Ubuntu/Debian
sudo apt-get install postgresql-15

# macOS
brew install postgresql@15

# Create database and user
sudo -u postgres psql
CREATE DATABASE webcraft_db;
CREATE USER webcraft WITH PASSWORD 'password';
GRANT ALL PRIVILEGES ON DATABASE webcraft_db TO webcraft;
\q

Redis Setup

Using Docker

# Redis is included in docker-compose.yml
# Default port: 6381

Manual Redis Installation

# Ubuntu/Debian
sudo apt-get install redis-server

# macOS
brew install redis

# Start Redis
redis-server

# Or as service
sudo systemctl start redis
sudo systemctl enable redis

Kafka Setup (Optional)

Kafka is required for real-time features like collaboration and event streaming.

Using Docker

# Kafka and Zookeeper are included in docker-compose.yml
# Kafka port: 9092
# Zookeeper port: 2181

Manual Installation

# Download Kafka
wget https://downloads.apache.org/kafka/2.13-3.6.0/kafka_2.13-3.6.0.tgz
tar -xzf kafka_2.13-3.6.0.tgz
cd kafka_2.13-3.6.0

# Start Zookeeper
bin/zookeeper-server-start.sh config/zookeeper.properties

# Start Kafka (in another terminal)
bin/kafka-server-start.sh config/server.properties

Environment Configuration

Create a .env file in the project root:

# Database
DATABASE_URL=postgresql://webcraft:password@localhost:5434/webcraft_db

# Redis
REDIS_URL=redis://localhost:6381

# Kafka
KAFKA_BOOTSTRAP_SERVERS=localhost:9092

# JWT Security
JWT_SECRET_KEY=your-secret-key-change-this
SECRET_KEY=your-secret-key-change-this

# API URLs
NEXT_PUBLIC_API_URL=http://localhost:8000
NEXT_PUBLIC_WS_URL=ws://localhost:8000

# Optional: AI Services
OPENAI_API_KEY=your-openai-key
ANTHROPIC_API_KEY=your-anthropic-key
GOOGLE_AI_API_KEY=your-google-ai-key

# Optional: Email Service
SMTP_HOST=smtp.sendgrid.net
SMTP_PORT=587
SMTP_USER=your-smtp-user
SMTP_PASSWORD=your-smtp-password

# Optional: Storage (AWS S3)
AWS_ACCESS_KEY_ID=your-access-key
AWS_SECRET_ACCESS_KEY=your-secret-key
AWS_REGION=us-east-1
AWS_S3_BUCKET=webcraft-assets

Verification

Verify that all services are running correctly:

Check API Health

curl http://localhost:8000/health

# Expected response:
{
  "status": "healthy",
  "version": "2.0.0",
  "services": {
    "database": "connected",
    "redis": "connected",
    "kafka": "connected"
  }
}

Check Database Connection

# Using Docker
docker exec -it webcraft-postgres-1 psql -U webcraft -d webcraft_db -c "SELECT version();"

# Using local PostgreSQL
psql -h localhost -p 5434 -U webcraft -d webcraft_db -c "SELECT version();"

Check Redis Connection

# Using Docker
docker exec -it webcraft-redis-1 redis-cli ping

# Using local Redis
redis-cli -p 6381 ping
# Should return: PONG

Troubleshooting

Port Conflicts

If ports are already in use, modify docker-compose.yml:

services:
  web:
    ports:
      - "3001:3000"  # Change 3000 to 3001
  api:
    ports:
      - "8001:8000"  # Change 8000 to 8001

Permission Issues

# Fix Docker permissions (Linux)
sudo usermod -aG docker $USER
newgrp docker

# Fix PostgreSQL permissions
sudo chown -R postgres:postgres /var/lib/postgresql

Database Migration Errors

cd apps/api

# Reset database (WARNING: Deletes all data)
alembic downgrade base
alembic upgrade head

# Or create fresh migration
alembic revision --autogenerate -m "Initial migration"
alembic upgrade head
