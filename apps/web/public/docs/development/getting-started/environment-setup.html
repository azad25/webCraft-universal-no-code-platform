Environment Setup

Configure your development environment for WebCraft

Overview

This guide will help you configure your development environment for WebCraft. We'll cover environment variables, database configuration, and service setup.

Environment Variables

WebCraft uses environment variables for configuration. Create a .env file in the project root.

Backend Environment Variables

# Application
APP_NAME=WebCraft API
APP_VERSION=2.0.0
DEBUG=true
ENVIRONMENT=development

# Server
HOST=0.0.0.0
PORT=8000
WORKERS=4

# Database - PostgreSQL
DATABASE_URL=postgresql://webcraft:password@localhost:5434/webcraft_db
DATABASE_POOL_SIZE=20
DATABASE_MAX_OVERFLOW=10

# Redis
REDIS_URL=redis://localhost:6381
REDIS_PASSWORD=
REDIS_DB=0
REDIS_CACHE_TTL=3600

# Kafka
KAFKA_BOOTSTRAP_SERVERS=localhost:9092
KAFKA_CONSUMER_GROUP=webcraft-api

# JWT Authentication
JWT_SECRET_KEY=your-secret-key-change-this-in-production
JWT_ALGORITHM=HS256
JWT_ACCESS_TOKEN_EXPIRE_MINUTES=30
JWT_REFRESH_TOKEN_EXPIRE_DAYS=7

# OAuth Providers (Optional)
GOOGLE_CLIENT_ID=
GOOGLE_CLIENT_SECRET=
GITHUB_CLIENT_ID=
GITHUB_CLIENT_SECRET=

# AI Services (Optional)
OPENAI_API_KEY=
ANTHROPIC_API_KEY=
GOOGLE_AI_API_KEY=

# Email Service (Optional)
SMTP_HOST=smtp.sendgrid.net
SMTP_PORT=587
SMTP_USER=
SMTP_PASSWORD=
FROM_EMAIL=noreply@webcraft.dev

# AWS S3 Storage (Optional)
AWS_ACCESS_KEY_ID=
AWS_SECRET_ACCESS_KEY=
AWS_REGION=us-east-1
AWS_S3_BUCKET=webcraft-assets

# Rate Limiting
RATE_LIMIT_REQUESTS_PER_MINUTE=100
RATE_LIMIT_BURST=20

# CORS
CORS_ORIGINS=http://localhost:3000,http://localhost:3001

Frontend Environment Variables

# API Configuration
NEXT_PUBLIC_API_URL=http://localhost:8000
NEXT_PUBLIC_WS_URL=ws://localhost:8000

# Feature Flags
NEXT_PUBLIC_ENABLE_AI=true
NEXT_PUBLIC_ENABLE_ANALYTICS=true

# Optional: Analytics
NEXT_PUBLIC_GA_ID=
NEXT_PUBLIC_SENTRY_DSN=

Database Configuration

PostgreSQL Setup

WebCraft requires PostgreSQL 15+. Configure your database connection:

Connection String Format

postgresql://[user]:[password]@[host]:[port]/[database]

Example Configurations

# Local Development
DATABASE_URL=postgresql://webcraft:password@localhost:5434/webcraft_db

# Docker
DATABASE_URL=postgresql://webcraft:password@postgres:5432/webcraft_db

# Production (with SSL)
DATABASE_URL=postgresql://user:pass@db.example.com:5432/webcraft_db?sslmode=require

Database Pool Settings

DATABASE_POOL_SIZE=20          # Number of connections in pool
DATABASE_MAX_OVERFLOW=10       # Additional connections allowed
DATABASE_POOL_TIMEOUT=30       # Timeout in seconds
DATABASE_POOL_RECYCLE=1800     # Recycle connections after 30 minutes

Redis Configuration

Redis is used for caching, sessions, and real-time features.

Connection String

# Local Development
REDIS_URL=redis://localhost:6381

# Docker
REDIS_URL=redis://redis:6379

# With Password
REDIS_URL=redis://:password@localhost:6381

# With Database Selection
REDIS_URL=redis://localhost:6381/0

Cache Configuration

REDIS_CACHE_TTL=3600  # Cache TTL in seconds (1 hour default)
REDIS_DB=0            # Database number (0-15)

Kafka Configuration

Kafka is used for event streaming and real-time collaboration.

Basic Setup

KAFKA_BOOTSTRAP_SERVERS=localhost:9092
KAFKA_CONSUMER_GROUP=webcraft-api

Multiple Brokers

KAFKA_BOOTSTRAP_SERVERS=broker1:9092,broker2:9092,broker3:9092

Authentication Setup

JWT Configuration

Generate secure secret keys for JWT tokens:

# Generate secret key (Python)
python -c "import secrets; print(secrets.token_urlsafe(32))"

# Generate secret key (OpenSSL)
openssl rand -base64 32

OAuth Providers

Configure OAuth for social login:

Google OAuth

  1. Go to Google Cloud Console
  2. Create a new project or select existing
  3. Enable Google+ API
  4. Create OAuth 2.0 credentials
  5. Add authorized redirect URIs: http://localhost:8000/api/v1/auth/google/callback

GitHub OAuth

  1. Go to GitHub Developer Settings
  2. Create a new OAuth App
  3. Set Authorization callback URL: http://localhost:8000/api/v1/auth/github/callback
  4. Copy Client ID and Client Secret

Configure AI providers for content generation and design assistance.

OpenAI

Anthropic Claude

ANTHROPIC_API_KEY=sk-ant-...

Google AI (Gemini)

GOOGLE_AI_API_KEY=...

Get your API key from Google AI Studio

Storage Configuration

AWS S3

AWS_ACCESS_KEY_ID=AKIA...
AWS_SECRET_ACCESS_KEY=...
AWS_REGION=us-east-1
AWS_S3_BUCKET=webcraft-assets
AWS_CLOUDFRONT_DOMAIN=cdn.example.com  # Optional

Local Storage

If not using S3, files will be stored locally in apps/api/storage/

Email Configuration

Configure email service for notifications and password resets.

SendGrid

SMTP_HOST=smtp.sendgrid.net
SMTP_PORT=587
SMTP_USER=apikey
SMTP_PASSWORD=SG.xxx  # Your SendGrid API key
FROM_EMAIL=noreply@webcraft.dev
FROM_NAME=WebCraft

Gmail SMTP

SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your-email@gmail.com
SMTP_PASSWORD=your-app-password  # Use App Password, not regular password

Development vs Production

Development Settings

DEBUG=true
ENVIRONMENT=development
CORS_ORIGINS=http://localhost:3000,http://localhost:3001

Production Settings

DEBUG=false
ENVIRONMENT=production
CORS_ORIGINS=https://yourdomain.com,https://www.yourdomain.com

# Use strong secrets
JWT_SECRET_KEY=very-long-random-string-here
SECRET_KEY=another-very-long-random-string-here

# Enable SSL for database
DATABASE_URL=postgresql://user:pass@host:5432/db?sslmode=require

Verification

Verify your environment configuration:

Check Environment Variables

# Backend
cd apps/api
python -c "from core.config import settings; print(settings.DATABASE_URL)"

# Frontend
cd apps/web
node -e "console.log(process.env.NEXT_PUBLIC_API_URL)"

Test Database Connection

# Using psql
psql $DATABASE_URL -c "SELECT version();"

# Using Python
python -c "from core.database import engine; print(engine.connect())"

Test Redis Connection

redis-cli -u $REDIS_URL ping
# Should return: PONG
