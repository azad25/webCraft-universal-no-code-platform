Build Your First App

A step-by-step guide to creating your first application with WebCraft

What You'll Build

In this tutorial, you'll create a simple landing page application with a header, hero section, features showcase, and contact form. This will introduce you to the core concepts of WebCraft including:

  • Using the drag-and-drop interface
  • Configuring widgets and components
  • Managing layouts and styling
  • Adding interactivity
  • Previewing and publishing your app

Final result: A professional landing page built with WebCraft

Prerequisites

  • ✅ WebCraft development environment set up
  • ✅ Basic understanding of HTML/CSS concepts
  • ✅ Familiarity with drag-and-drop interfaces
  • ✅ Modern web browser (Chrome, Firefox, Safari, Edge)

If you haven't set up your development environment yet, please follow the Getting Started guide first.

Step 1: Create a New Project

  1. Open WebCraft

    Navigate to your local WebCraft instance (typically http://localhost:3000)

  2. Create New Project

    Click the "Create New Project" button on the dashboard

    // Project configuration
{
  "name": "My Landing Page",
  "description": "A simple landing page for my product",
  "template": "blank", // Start with a blank canvas
  "responsive": true,
  "theme": "default"
}
  3. Enter Project Details
    • Project Name: "My Landing Page"
    • Description: "A simple landing page for my product"
    • Template: Select "Blank Canvas"
    • Responsive: Enable responsive design
  4. Click Create

    You'll be redirected to the WebCraft editor

💡 Pro Tip: Starting with a blank canvas gives you full control over your design, but you can also choose from pre-built templates to speed up development.

Step 2: Familiarize Yourself with the Editor

The WebCraft editor has several key areas:

Editor Interface

  1. Left Sidebar - Widget Library
    • Basic widgets (Text, Image, Button)
    • Layout widgets (Container, Grid, Flex)
    • Form widgets (Input, Select, Checkbox)
    • Advanced widgets (Chart, Map, Video)
  2. Center Canvas
    • Your design workspace
    • Drag-and-drop area
    • Responsive preview modes
    • Zoom controls
  3. Right Sidebar - Properties Panel
    • Widget properties and settings
    • Style customization
    • Animation settings
    • Event handlers
  4. Top Toolbar
    • Save, preview, and publish buttons
    • Undo/redo controls
    • View mode selector
    • Project settings
// Editor state structure
{
  "canvas": {
    "width": 1200,
    "height": 800,
    "zoom": 1.0,
    "device": "desktop" // desktop, tablet, mobile
  },
  "selectedWidget": null,
  "widgets": [],
  "history": {
    "undo": [],
    "redo": []
  }
}

Step 3: Build the Header Section

Add a Container for the Header

  1. Drag a Container Widget

    From the left sidebar, drag a "Container" widget to the top of your canvas

  2. Configure Container Properties 
    // Container configuration
{
  "width": "100%",
  "height": "80px",
  "backgroundColor": "#ffffff",
  "borderBottom": "1px solid #e0e0e0",
  "padding": "0 20px",
  "display": "flex",
  "alignItems": "center",
  "justifyContent": "space-between"
}
  3. Add Logo Text
    • Drag a "Text" widget inside the container
    • Set text to "YourBrand"
    • Configure text properties:
      • Font size: 24px
      • Font weight: bold
      • Color: #333333
  4. Add Navigation Menu
    • Drag a "Flex Container" next to the logo
    • Add three "Button" widgets inside the flex container
    • Set button texts: "Home", "Features", "Contact"
    • Configure button styles:
      • Background: transparent
      • Text color: #666666
      • Border: none
      • Margin: 0 10px
// Header widget structure
{
  "id": "header-container",
  "type": "container",
  "children": [
    {
      "id": "logo-text",
      "type": "text",
      "properties": {
        "text": "YourBrand",
        "fontSize": 24,
        "fontWeight": "bold",
        "color": "#333333"
      }
    },
    {
      "id": "nav-container",
      "type": "flex-container",
      "children": [
        {
          "id": "nav-home",
          "type": "button",
          "properties": {
            "text": "Home",
            "variant": "text",
            "color": "#666666"
          }
        },
        // ... other navigation items
      ]
    }
  ]
}

Step 4: Create the Hero Section

Add Hero Container

  1. Drag a New Container

    Place it below the header, spanning the full width

  2. Configure Hero Container 
    // Hero container configuration
{
  "width": "100%",
  "height": "500px",
  "backgroundColor": "#f8f9fa",
  "display": "flex",
  "flexDirection": "column",
  "alignItems": "center",
  "justifyContent": "center",
  "textAlign": "center",
  "padding": "40px 20px"
}
  3. Add Hero Title
    • Drag a "Text" widget into the hero container
    • Set text to "Build Amazing Apps Without Code"
    • Configure properties:
      • Font size: 48px
      • Font weight: bold
      • Color: #2c3e50
      • Margin bottom: 20px
  4. Add Hero Subtitle
    • Drag another "Text" widget
    • Set text to "Create professional applications with our intuitive drag-and-drop interface"
    • Configure properties:
      • Font size: 20px
      • Color: #7f8c8d
      • Margin bottom: 30px
      • Max width: 600px
  5. Add Call-to-Action Button
    • Drag a "Button" widget
    • Set text to "Get Started"
    • Configure properties:
      • Background color: #3498db
      • Text color: white
      • Font size: 18px
      • Padding: 15px 30px
      • Border radius: 5px

Step 5: Add Features Section

Create Features Container

  1. Add Section Container

    Drag a container below the hero section

  2. Configure Section 
    // Features section configuration
{
  "width": "100%",
  "padding": "80px 20px",
  "backgroundColor": "#ffffff"
}
  3. Add Section Title
    • Text: "Why Choose WebCraft?"
    • Font size: 36px
    • Text align: center
    • Margin bottom: 50px
  4. Create Features Grid
    • Drag a "Grid" widget into the section
    • Set grid properties:
      • Columns: 3
      • Gap: 30px
      • Max width: 1200px
      • Margin: 0 auto
  5. Add Feature Cards

    For each feature (repeat 3 times):

    • Drag a "Card" widget into a grid cell
    • Configure card properties:
      • Padding: 30px
      • Background: white
      • Border: 1px solid #e0e0e0
      • Border radius: 8px
      • Text align: center
    • Add content to each card:
      • Icon (use Text widget with emoji: 🚀, ⚡, 🔧)
      • Title (Text widget)
      • Description (Text widget)
// Feature card content examples
[
  {
    "icon": "🚀",
    "title": "Fast Development",
    "description": "Build apps 10x faster with our intuitive interface"
  },
  {
    "icon": "⚡",
    "title": "Powerful Features",
    "description": "Advanced functionality without complex coding"
  },
  {
    "icon": "🔧",
    "title": "Fully Customizable",
    "description": "Tailor every aspect to your specific needs"
  }
]

Step 6: Create Contact Form

Add Contact Section

  1. Create Contact Container

    Drag a container at the bottom of your page

  2. Configure Contact Section 
    // Contact section configuration
{
  "width": "100%",
  "padding": "80px 20px",
  "backgroundColor": "#f8f9fa"
}
  3. Add Contact Title
    • Text: "Get In Touch"
    • Font size: 36px
    • Text align: center
    • Margin bottom: 50px
  4. Create Form Container
    • Drag a container for the form
    • Set max width: 600px
    • Center align: margin auto
  5. Add Form Fields
    • Name input field
    • Email input field
    • Message textarea
    • Submit button
  6. Configure Form Fields 
    // Form field configurations
{
  "nameField": {
    "type": "input",
    "placeholder": "Your Name",
    "required": true
  },
  "emailField": {
    "type": "input",
    "placeholder": "Your Email",
    "inputType": "email",
    "required": true
  },
  "messageField": {
    "type": "textarea",
    "placeholder": "Your Message",
    "rows": 5,
    "required": true
  },
  "submitButton": {
    "type": "button",
    "text": "Send Message",
    "variant": "primary"
  }
}

Step 7: Add Styling and Responsiveness

Apply Global Styles

  1. Access Global Styles

    Click on the "Global Styles" button in the top toolbar

  2. Configure Typography 
    // Global typography settings
{
  "fontFamily": "Inter, sans-serif",
  "headingFontFamily": "Inter, sans-serif",
  "baseFontSize": "16px",
  "lineHeight": "1.6",
  "headingWeights": {
    "h1": "700",
    "h2": "600", 
    "h3": "600"
  }
}
  3. Set Color Scheme 
    // Color scheme
{
  "primaryColor": "#3498db",
  "secondaryColor": "#2ecc71",
  "textColor": "#2c3e50",
  "backgroundColor": "#ffffff",
  "borderColor": "#e0e0e0"
}

Configure Responsive Breakpoints

  1. Switch to Mobile View

    Use the device selector in the top toolbar

  2. Adjust Layout for Mobile
    • Stack navigation items vertically
    • Reduce font sizes
    • Adjust padding and margins
    • Make form fields full width
  3. Test Tablet View

    Repeat the process for tablet breakpoints

// Responsive configuration
{
  "breakpoints": {
    "mobile": "768px",
    "tablet": "1024px",
    "desktop": "1200px"
  },
  "mobileAdjustments": {
    "heroTitleSize": "32px",
    "sectionTitleSize": "24px",
    "featureGridColumns": 1,
    "navigationLayout": "vertical"
  }
}

Step 8: Add Interactivity

Configure Button Actions

  1. Select the CTA Button

    Click on the "Get Started" button in the hero section

  2. Add Click Handler

    In the properties panel, find the "Events" section

  3. Configure Scroll Action 
    // Button click handler
{
  "event": "click",
  "action": "scrollTo",
  "target": "#features-section",
  "duration": 800,
  "easing": "easeInOut"
}
  4. Add Form Submission

    For the contact form submit button:

    // Form submission handler
{
  "event": "submit",
  "action": "apiCall",
  "endpoint": "/api/contact",
  "method": "POST",
  "data": {
    "name": "{{nameField.value}}",
    "email": "{{emailField.value}}",
    "message": "{{messageField.value}}"
  },
  "successMessage": "Thank you! We'll be in touch soon.",
  "errorMessage": "Sorry, there was an error sending your message."
}

Add Smooth Scrolling

// Smooth scrolling configuration
{
  "scrollBehavior": "smooth",
  "navigation": {
    "home": "#hero-section",
    "features": "#features-section",
    "contact": "#contact-section"
  }
}

Step 9: Preview and Test

Preview Your App

  1. Click Preview Button

    Use the preview button in the top toolbar

  2. Test All Functionality
    • Test navigation links
    • Verify responsive design
    • Test form submission
    • Check all interactive elements
  3. Test on Different Devices

    Use browser developer tools to simulate different screen sizes

Debug Common Issues

Layout Issues

  • Check container widths and positioning
  • Verify responsive breakpoints
  • Ensure proper flexbox/grid settings

Interactive Elements Not Working

  • Verify event handler configurations
  • Check target element IDs
  • Test API endpoints

Step 10: Publish Your App

Save Your Project

  1. Click Save

    Use Ctrl+S (Cmd+S on Mac) or click the save button

  2. Add Version Notes

    Document what changed in this version

Publish Settings

  1. Click Publish Button

    Access publish settings from the top toolbar

  2. Configure Publishing Options 
    // Publishing configuration
{
  "domain": "my-landing-page.webcraft.app",
  "ssl": true,
  "analytics": true,
  "seo": {
    "title": "My Amazing Product - Build Apps Without Code",
    "description": "Create professional applications with our intuitive drag-and-drop interface",
    "keywords": ["no-code", "app builder", "drag and drop"]
  },
  "performance": {
    "minify": true,
    "compress": true,
    "cache": true
  }
}
  3. Deploy to Production

    Click "Publish Now" to deploy your app
