Next.js Setup Guide

Complete guide to setting up Next.js 15 for WebCraft development

Overview

WebCraft uses Next.js 15 with App Router for the frontend. This guide covers the complete setup process, configuration options, and best practices for development.

Prerequisites:
  • Node.js 18+
  • npm, yarn, or pnpm
  • Basic React knowledge

Project Structure

Next.js follows a specific directory structure that WebCraft leverages for optimal organization:

apps/web/
├── app/                    # App Router directory
│   ├── (auth)/            # Route groups
│   ├── (dashboard)/       # Dashboard routes
│   ├── api/               # API routes
│   ├── globals.css        # Global styles
│   ├── layout.tsx         # Root layout
│   └── page.tsx           # Home page
├── components/            # Reusable components
│   ├── ui/               # UI components
│   ├── widgets/          # Widget components
│   └── shared/           # Shared components
├── lib/                   # Utility functions
├── hooks/                 # Custom React hooks
├── store/                 # Redux store configuration
├── types/                 # TypeScript types
└── public/               # Static assets

Installation & Setup

1. Install Dependencies

cd apps/web
npm install

2. Environment Configuration

Create a .env.local file:

# API Configuration
NEXT_PUBLIC_API_URL=http://localhost:8000
NEXT_PUBLIC_WS_URL=ws://localhost:8000

# Authentication
NEXTAUTH_URL=http://localhost:3000
NEXTAUTH_SECRET=your-secret-key

# Feature Flags
NEXT_PUBLIC_ENABLE_REALTIME=true
NEXT_PUBLIC_ENABLE_ANALYTICS=true

# Development
NODE_ENV=development

Next.js Configuration

next.config.js

/** @type {import('next').NextConfig} */
const nextConfig = {
  experimental: {
    appDir: true,
    serverComponentsExternalPackages: ['@react-dnd/backend'],
  },
  
  // Image optimization
  images: {
    domains: ['localhost', 'api.webcraft.dev'],
    formats: ['image/avif', 'image/webp'],
  },
  
  // API proxy for development
  async rewrites() {
    return [
      {
        source: '/api/:path*',
        destination: 'http://localhost:8000/api/:path*',
      },
    ];
  },
  
  // Webpack configuration
  webpack: (config, { isServer }) => {
    if (!isServer) {
      config.resolve.fallback = {
        ...config.resolve.fallback,
        fs: false,
        net: false,
        tls: false,
      };
    }
    return config;
  },
  
  // Environment variables
  env: {
    CUSTOM_KEY: process.env.CUSTOM_KEY,
  },
};

module.exports = nextConfig;

Best Practices

Performance Optimization

  • Use next/image for optimized images
  • Implement dynamic imports for heavy components
  • Leverage Server Components for static content
  • Use loading.tsx for loading states
  • Implement proper error boundaries

Code Organization

  • Keep components small and focused
  • Use custom hooks for reusable logic
  • Separate business logic from UI components
  • Follow consistent naming conventions
  • Document complex components with JSDoc

TypeScript Guidelines

  • Use strict TypeScript configuration
  • Avoid any types
  • Create proper interfaces for props
  • Use utility types effectively
  • Export types alongside components

Common Issues & Solutions

Build Errors with React DnD

If you encounter build errors with React DnD, ensure you have the correct backend configured:

// Use HTML5Backend for web
import { HTML5Backend } from 'react-dnd-html5-backend'

// For touch devices, use TouchBackend
import { TouchBackend } from 'react-dnd-touch-backend'

TypeScript Path Resolution

If TypeScript can't resolve your path aliases, ensure your tsconfig.json is properly configured and restart your IDE.

Hot Reload Not Working

Check that your files are in the correct directories and that you're using the latest version of Next.js.
