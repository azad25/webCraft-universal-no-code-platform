Module System

Understanding WebCraft's plugin architecture

Overview

WebCraft uses a powerful module system that allows features to be dynamically loaded, enabled, and disabled without restarting the application. This plugin architecture makes the platform highly extensible.

Module Architecture

All modules inherit from BaseModule and implement a standard interface:

Base Module Class

from abc import ABC, abstractmethod
from core.module_system import BaseModule, ModuleMetadata, ModuleType

class BaseModule(ABC):
    """Base class for all modules"""
    
    def __init__(self, config: Dict[str, Any] = None):
        self.config = config or {}
        self._initialized = False
        self._hooks: Dict[str, List[Callable]] = {}
    
    @property
    @abstractmethod
    def metadata(self) -> ModuleMetadata:
        """Return module metadata"""
        pass
    
    @abstractmethod
    async def initialize(self) -> bool:
        """Initialize the module"""
        pass
    
    @abstractmethod
    async def shutdown(self) -> bool:
        """Cleanup when module is disabled"""
        pass
    
    def get_routes(self) -> List[Any]:
        """Return FastAPI routes for this module"""
        return []
    
    def get_frontend_components(self) -> Dict[str, Any]:
        """Return frontend component definitions"""
        return {}

Creating a Custom Module

Here's a complete example of creating a custom module:

from core.module_system import BaseModule, ModuleMetadata, ModuleType
from fastapi import APIRouter
from typing import Dict, Any

class MyCustomModule(BaseModule):
    """Example custom module"""
    
    @property
    def metadata(self) -> ModuleMetadata:
        return ModuleMetadata(
            id="custom.my_module",
            name="My Custom Module",
            version="1.0.0",
            type=ModuleType.INTEGRATION,
            description="Custom functionality for specific use case",
            author="Your Name",
            dependencies=["core.widgets"],  # Requires widgets module
            is_premium=False,
            price=0.0,
            tags=["custom", "integration"]
        )
    
    async def initialize(self) -> bool:
        """Initialize the module"""
        try:
            # Setup code here
            self._initialized = True
            print(f"✅ Module {self.metadata.id} initialized")
            return True
        except Exception as e:
            print(f"❌ Failed to initialize module: {e}")
            return False
    
    async def shutdown(self) -> bool:
        """Cleanup when module is disabled"""
        try:
            # Cleanup code here
            self._initialized = False
            return True
        except Exception as e:
            print(f"❌ Failed to shutdown module: {e}")
            return False
    
    def get_routes(self) -> List[Any]:
        """Return FastAPI routes"""
        router = APIRouter()
        
        @router.get("/custom-endpoint")
        async def custom_endpoint():
            return {"message": "Hello from custom module"}
        
        return [router]

Module Registry

The module registry manages all modules in the system:

Registering a Module

from core.module_system import module_registry
from modules.my_module import MyCustomModule

# Register module class
module_registry.register_module_class(MyCustomModule)

# Enable module
await module_registry.enable_module("custom.my_module", config={})

# Get module instance
module = module_registry.get_module("custom.my_module")

# Disable module
await module_registry.disable_module("custom.my_module")

Module Registry Methods

  • register_module_class(module_class) - Register a module class
  • enable_module(module_id, config) - Enable and initialize a module
  • disable_module(module_id) - Disable a module
  • get_module(module_id) - Get an enabled module instance
  • get_all_modules() - Get all enabled modules
  • get_available_modules() - Get all available module metadata
  • get_modules_by_type(module_type) - Get modules by type

Module Hooks

Modules can register hooks to respond to system events:

class MyModule(BaseModule):
    async def initialize(self) -> bool:
        # Register hooks
        self.register_hook("app.created", self.on_app_created)
        self.register_hook("app.updated", self.on_app_updated)
        return True
    
    async def on_app_created(self, data: Dict):
        """Called when an app is created"""
        app_id = data.get("app_id")
        print(f"App {app_id} was created")
    
    async def on_app_updated(self, data: Dict):
        """Called when an app is updated"""
        app_id = data.get("app_id")
        print(f"App {app_id} was updated")

Available Hooks

  • module.enabled - Module enabled
  • module.disabled - Module disabled
  • app.created - App created
  • app.updated - App updated
  • app.deleted - App deleted
  • page.created - Page created
  • widget.added - Widget added

Module Dependencies

Modules can declare dependencies on other modules:

@property
def metadata(self) -> ModuleMetadata:
    return ModuleMetadata(
        id="custom.advanced_module",
        dependencies=["core.widgets", "core.integrations"],
        # ...
    )

The module system automatically ensures dependencies are enabled before initializing a module.

Module Configuration

Modules can accept configuration during initialization:

# Enable module with configuration
config = {
    "api_key": "your-api-key",
    "endpoint": "https://api.example.com",
    "timeout": 30
}

await module_registry.enable_module(
    "custom.my_module",
    config=config
)

# Access config in module
class MyModule(BaseModule):
    async def initialize(self) -> bool:
        api_key = self.config.get("api_key")
        endpoint = self.config.get("endpoint")
        # Use configuration
        return True

Module Routes

Modules can provide FastAPI routes that are automatically registered:

def get_routes(self) -> List[Any]:
    router = APIRouter(prefix="/custom", tags=["Custom Module"])
    
    @router.get("/status")
    async def get_status():
        return {"status": "active", "module": self.metadata.id}
    
    @router.post("/action")
    async def perform_action(data: Dict):
        # Module-specific logic
        return {"result": "success"}
    
    return [router]

Routes are automatically prefixed with /api/v1 when registered.

Frontend Module Integration

Modules can also provide frontend components:

def get_frontend_components(self) -> Dict[str, Any]:
    return {
        "CustomWidget": {
            "component": "CustomWidget",
            "props": {
                "title": {"type": "string", "default": "Custom"},
                "content": {"type": "richtext", "default": ""}
            },
            "category": "custom"
        }
    }

Module Lifecycle

  1. Registration - Module class is registered with the registry
  2. Enable - Module is enabled, dependencies checked
  3. Initialize - initialize() method called
  4. Active - Module is active and handling requests
  5. Shutdown - shutdown() method called when disabled

Best Practices

  • Idempotent Initialization - Initialize should be safe to call multiple times
  • Graceful Shutdown - Clean up resources properly in shutdown
  • Error Handling - Handle errors gracefully and return False on failure
  • Dependency Management - Declare all dependencies explicitly
  • Configuration Validation - Validate configuration in initialize
  • Resource Cleanup - Release all resources in shutdown

Example: Complete Module

from core.module_system import BaseModule, ModuleMetadata, ModuleType
from fastapi import APIRouter
from typing import Dict, Any

class WeatherModule(BaseModule):
    """Weather integration module"""
    
    @property
    def metadata(self) -> ModuleMetadata:
        return ModuleMetadata(
            id="integrations.weather",
            name="Weather Integration",
            version="1.0.0",
            type=ModuleType.INTEGRATION,
            description="Weather data integration",
            author="WebCraft Team",
            dependencies=[],
            tags=["weather", "api"]
        )
    
    async def initialize(self) -> bool:
        api_key = self.config.get("api_key")
        if not api_key:
            print("⚠️ Weather API key not configured")
            return False
        
        self.api_key = api_key
        self._initialized = True
        return True
    
    async def shutdown(self) -> bool:
        self._initialized = False
        return True
    
    def get_routes(self) -> List[Any]:
        router = APIRouter(prefix="/weather", tags=["Weather"])
        
        @router.get("/current")
        async def get_current_weather(city: str):
            # Fetch weather data
            return {"city": city, "temperature": 72}
        
        return [router]
