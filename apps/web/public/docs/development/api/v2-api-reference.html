WebCraft API v2 Reference

Complete API documentation for the domain-driven v2 architecture

API Overview

The WebCraft API v2 uses a domain-driven architecture with 34 specialized domains covering all platform functionality.

Base URL

https://api.webcraft.dev/api/v2

Authentication

All API requests require authentication via JWT Bearer token or API key.

Authorization: Bearer <your-token>

API Domains

Authentication

User authentication, registration, OAuth, and API key management.

  • POST /auth/login - User login
  • POST /auth/register - User registration
  • POST /auth/refresh - Refresh token
  • GET /auth/me - Get current user
  • POST /auth/api-keys - Create API key

Apps

Application CRUD, publishing, deployment, and settings.

  • GET /apps - List apps
  • POST /apps - Create app
  • GET /apps/{id} - Get app
  • PUT /apps/{id} - Update app
  • POST /apps/{id}/publish - Publish app

Pages

Page management, content, and SEO settings.

  • GET /apps/{id}/pages - List pages
  • POST /apps/{id}/pages - Create page
  • PUT /apps/{id}/pages/{pageId} - Update page
  • DELETE /apps/{id}/pages/{pageId} - Delete page

Widgets

Widget marketplace, CRUD, and configuration.

  • GET /widgets - List widgets
  • GET /widgets/categories - Get categories
  • GET /apps/{id}/widgets - App widgets
  • POST /apps/{id}/widgets - Add widget

Widget Layers

Widget decomposition and sub-element management.

  • GET /apps/{id}/widget-layers/{elementId}/decompose - Decompose widget
  • PUT /apps/{id}/widget-layers/{elementId}/sub-element/{path} - Update sub-element
  • GET /apps/{id}/widget-layers/supported-widgets - Supported widgets

Media

File uploads, CDN, and media optimization.

  • POST /apps/{id}/media/upload - Upload file
  • GET /apps/{id}/media - List media
  • DELETE /apps/{id}/media/{mediaId} - Delete media

AI

AI content generation, chat, and analysis.

  • POST /ai/generate-content - Generate content
  • POST /ai/chat - AI chat
  • POST /ai/analyze-design - Analyze design
  • POST /ai/suggest-improvements - Get suggestions

Automation

Workflows, triggers, and scheduling.

  • GET /apps/{id}/automations - List automations
  • POST /apps/{id}/automations - Create automation
  • POST /apps/{id}/automations/{autoId}/execute - Execute

Collections

User databases and CRUD operations.

  • GET /apps/{id}/collections - List collections
  • POST /apps/{id}/collections - Create collection
  • GET /apps/{id}/collections/{colId}/records - Get records
  • POST /apps/{id}/collections/{colId}/records - Create record

CRM

Contact management, deals, pipeline, and activities.

  • GET /apps/{id}/crm/stats - CRM statistics
  • GET /apps/{id}/crm/contacts - List contacts
  • POST /apps/{id}/crm/contacts - Create contact
  • GET /apps/{id}/crm/deals - List deals
  • GET /apps/{id}/crm/pipeline - Pipeline view

E-commerce

Products, orders, and inventory management.

  • GET /apps/{id}/ecommerce/products - List products
  • POST /apps/{id}/ecommerce/products - Create product
  • GET /apps/{id}/ecommerce/orders - List orders
  • GET /apps/{id}/ecommerce/inventory - Inventory

Payment

Subscriptions, billing, and Stripe integration.

  • GET /payment/plans - List plans
  • POST /payment/subscribe - Subscribe
  • GET /payment/subscription - Get subscription
  • POST /payment/cancel - Cancel subscription

Analytics

Traffic, conversions, and performance metrics.

  • GET /apps/{id}/analytics/overview - Overview
  • GET /apps/{id}/analytics/traffic - Traffic data
  • GET /apps/{id}/analytics/conversions - Conversions
  • GET /apps/{id}/analytics/performance - Performance

SEO

Meta tags, sitemaps, and optimization.

  • GET /apps/{id}/seo/analysis - SEO analysis
  • PUT /apps/{id}/seo/meta - Update meta
  • GET /apps/{id}/seo/sitemap - Generate sitemap

Integrations

14+ third-party service integrations.

  • GET /integrations - List integrations
  • POST /apps/{id}/integrations/{type}/connect - Connect
  • DELETE /apps/{id}/integrations/{type} - Disconnect

Notifications

Email, SMS, push, and in-app notifications.

  • POST /notifications/send - Send notification
  • GET /notifications - List notifications
  • PUT /notifications/settings - Update settings

Webhooks

Incoming and outgoing webhooks.

  • GET /apps/{id}/webhooks - List webhooks
  • POST /apps/{id}/webhooks - Create webhook
  • POST /apps/{id}/webhooks/{whId}/test - Test webhook

Mobile

Mobile SDK and push notifications.

  • GET /mobile/apps/{id}/config - App config
  • POST /mobile/apps/{id}/push - Send push
  • GET /mobile/sdk/{platform} - Download SDK

Scrapers

Web scraping and data extraction.

  • GET /apps/{id}/scrapers - List scrapers
  • POST /apps/{id}/scrapers - Create scraper
  • POST /apps/{id}/scrapers/{scId}/run - Run scraper
  • GET /apps/{id}/scrapers/{scId}/data - Get data

SDK

Multi-language SDK generation.

  • GET /sdk/languages - Supported languages
  • POST /sdk/apps/{id}/generate - Generate SDK
  • GET /sdk/apps/{id}/download/{lang} - Download SDK

GraphQL

GraphQL API interface.

  • POST /graphql - Execute query
  • GET /graphql - GraphQL Playground
  • GET /graphql/schema - Get schema

Export

Static export to GitHub, Netlify, Vercel.

  • POST /apps/{id}/export/static - Export static
  • POST /apps/{id}/export/github - Export to GitHub
  • POST /apps/{id}/export/netlify - Deploy to Netlify
  • POST /apps/{id}/export/vercel - Deploy to Vercel

Setup

Platform setup and installation wizard.

  • GET /setup/status - Setup status
  • GET /setup/requirements - System requirements
  • POST /setup/initialize - Initialize platform
  • GET /setup/progress - Setup progress

Code Examples

JavaScript/TypeScript

// Initialize SDK
const webcraft = new WebCraftSDK('your-api-key');

// Create an app
const app = await webcraft.apps.create({
  name: 'My App',
  appType: 'website',
  description: 'My awesome website'
});

// Add a page
const page = await webcraft.pages.create(app.id, {
  title: 'Home',
  slug: 'home',
  isHomepage: true
});

// Generate AI content
const content = await webcraft.ai.generateContent({
  prompt: 'Write a hero section for a SaaS landing page',
  type: 'hero'
});

Python

from webcraft import WebCraftSDK

# Initialize SDK
sdk = WebCraftSDK('your-api-key')

# Create an app
app = sdk.apps.create(
    name='My App',
    app_type='website',
    description='My awesome website'
)

# List collections
collections = sdk.collections.list(app.id)

# Create a record
record = sdk.collections.create_record(
    app.id,
    collection_id='contacts',
    data={'name': 'John Doe', 'email': 'john@example.com'}
)

cURL

# Get apps
curl -X GET "https://api.webcraft.dev/api/v2/apps" \
  -H "Authorization: Bearer YOUR_TOKEN"

# Create app
curl -X POST "https://api.webcraft.dev/api/v2/apps" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name": "My App", "appType": "website"}'

# Generate AI content
curl -X POST "https://api.webcraft.dev/api/v2/ai/generate-content" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "Write a hero section", "type": "hero"}'
