Pages API

Complete API reference for page management

Overview

The Pages API provides endpoints for creating, managing, and publishing pages within applications. Pages contain the visual content and structure of your application.

Base URL

http://localhost:8000/api/v1/apps/{app_id}/pages

List Pages

Get all pages for an application.

Request

GET /api/v1/apps/{app_id}/pages
Authorization: Bearer {token}

Query Parameters:
- is_published: bool (optional) - Filter by published status

Response

{
  "pages": [
    {
      "id": "uuid",
      "title": "Home Page",
      "slug": "home",
      "is_homepage": true,
      "is_published": true,
      "updated_at": "2024-01-01T00:00:00"
    }
  ],
  "total": 5
}

Example

curl -X GET "http://localhost:8000/api/v1/apps/{app_id}/pages" \
  -H "Authorization: Bearer YOUR_TOKEN"

Create Page

Create a new page in an application.

Request

POST /api/v1/apps/{app_id}/pages
Authorization: Bearer {token}
Content-Type: application/json

{
  "title": "About Us",
  "slug": "about",
  "content": {
    "elements": [],
    "settings": {}
  },
  "is_homepage": false,
  "is_published": false,
  "meta_title": "About Us",
  "meta_description": "Learn more about us",
  "meta_keywords": "about, company"
}

Response

{
  "id": "uuid",
  "app_id": "uuid",
  "title": "About Us",
  "slug": "about",
  "content": {...},
  "is_homepage": false,
  "is_published": false,
  "created_at": "2024-01-01T00:00:00",
  "updated_at": "2024-01-01T00:00:00"
}

Update Page

Update an existing page. Only provided fields will be updated.

Request

PUT /api/v1/apps/{app_id}/pages/{page_id}
Authorization: Bearer {token}
Content-Type: application/json

{
  "title": "Updated Page Title",
  "content": {
    "elements": [...],
    "settings": {...}
  },
  "is_published": true
}

Response

{
  "id": "uuid",
  "title": "Updated Page Title",
  "updated_at": "2024-01-01T00:00:00",
  ...
}

Delete Page

Delete a page from an application.

Request

DELETE /api/v1/apps/{app_id}/pages/{page_id}
Authorization: Bearer {token}

Response

{
  "message": "Page deleted successfully"
}

Set Homepage

Set a page as the homepage for an application.

Request

POST /api/v1/apps/{app_id}/pages/{page_id}/set-homepage
Authorization: Bearer {token}

Response

{
  "message": "Homepage updated successfully",
  "page": {
    "id": "uuid",
    "is_homepage": true
  }
}

Page Content Structure

Pages contain a content object with elements and settings:

{
  "content": {
    "elements": [
      {
        "id": "unique-element-id",
        "type": "widget-type",
        "position": {
          "x": 0,
          "y": 0
        },
        "size": {
          "width": 800,
          "height": 100
        },
        "props": {
          // Widget-specific properties
        },
        "style": {
          // CSS styles
        },
        "children": [] // Nested elements
      }
    ],
    "settings": {
      "backgroundColor": "#ffffff",
      "maxWidth": "1200px",
      "padding": "20px"
    }
  }
}

Element Structure

Each element in a page follows this structure:

interface Element {
  id: string
  type: string  // Widget type (e.g., 'text', 'image', 'button')
  position: {
    x: number
    y: number
  }
  size: {
    width: number
    height: number
  }
  props: Record  // Widget-specific props
  style: Record  // CSS styles
  children?: Element[]  // Nested elements
  locked?: boolean
  visible?: boolean
  zIndex?: number
}

TypeScript Client Example

import { apiClient } from '@/lib/api-client'

// List pages
const getPages = async (appId: string, isPublished?: boolean) => {
  const response = await apiClient.get(`/api/apps/${appId}/pages`, {
    params: { is_published: isPublished }
  })
  return response.data
}

// Get page
const getPage = async (appId: string, pageId: string) => {
  const response = await apiClient.get(`/api/apps/${appId}/pages/${pageId}`)
  return response.data
}

// Create page
const createPage = async (appId: string, pageData: {
  title: string
  slug: string
  content?: any
  is_homepage?: boolean
  is_published?: boolean
}) => {
  const response = await apiClient.post(`/api/apps/${appId}/pages`, pageData)
  return response.data
}

// Update page
const updatePage = async (
  appId: string,
  pageId: string,
  updates: Partial
) => {
  const response = await apiClient.put(
    `/api/apps/${appId}/pages/${pageId}`,
    updates
  )
  return response.data
}

// Delete page
const deletePage = async (appId: string, pageId: string) => {
  const response = await apiClient.delete(
    `/api/apps/${appId}/pages/${pageId}`
  )
  return response.data
}

// Set homepage
const setHomepage = async (appId: string, pageId: string) => {
  const response = await apiClient.post(
    `/api/apps/${appId}/pages/${pageId}/set-homepage`
  )
  return response.data
}

Error Responses

All endpoints may return these error responses:

401 Unauthorized

{
  "detail": "Could not validate credentials"
}

404 Not Found

{
  "detail": "Page not found"
}

400 Bad Request

{
  "detail": "Validation error message"
}
