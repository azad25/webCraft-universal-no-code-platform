Widgets API

Complete API reference for widget management and marketplace

Overview

The Widgets API provides endpoints for managing reusable components, widgets marketplace, and widget configurations. Widgets are the building blocks of WebCraft applications.

Base URL

http://localhost:8000/api/v1/widgets

Built-in Widget Categories

WebCraft includes 60+ built-in widgets organized into categories:

Layout Widgets

  • container - Flexible container for organizing content
  • section - Full-width section with background options
  • columns - Multi-column layout system
  • grid - CSS Grid layout container
  • spacer - Add spacing between elements

Content Widgets

  • heading - H1-H6 headings with styling
  • text - Rich text with formatting
  • paragraph - Paragraph text block
  • list - Ordered and unordered lists
  • quote - Blockquote with styling

Media Widgets

  • image - Responsive images with effects
  • gallery - Image gallery with lightbox
  • video - Video player with controls
  • icon - Icon with customizable styling

Interactive Widgets

  • button - Interactive button with actions
  • form - Contact and data collection forms
  • input - Form input field
  • select - Dropdown selection

Business Widgets

  • chart - Data visualization charts
  • table - Data tables with sorting
  • pricing - Pricing table widget
  • testimonial - Customer testimonials

E-commerce Widgets

  • product - Product showcase card
  • cart - Shopping cart widget
  • checkout - Checkout form

Advanced Widgets

  • map - Interactive maps
  • calendar - Event calendar
  • social - Social media integration
  • custom - Custom HTML/CSS/JS

List Widgets

Get a paginated list of available widgets.

Request

GET /api/v1/widgets
Authorization: Bearer {token}

Query Parameters:
- page: int (default: 1) - Page number
- per_page: int (default: 20, max: 100) - Items per page
- category: string (optional) - Filter by category
- search: string (optional) - Search in names and descriptions
- is_premium: bool (optional) - Filter premium widgets

Response

{
  "widgets": [
    {
      "id": "uuid",
      "name": "Text Widget",
      "slug": "text",
      "description": "Rich text with formatting",
      "category": "content",
      "config_schema": {
        "text": {"type": "string"},
        "fontSize": {"type": "string"},
        "color": {"type": "string"}
      },
      "default_config": {
        "text": "Enter text here",
        "fontSize": "16px"
      },
      "is_premium": false,
      "price": 0,
      "downloads": 1250,
      "rating": 4.5,
      "created_at": "2024-01-01T00:00:00"
    }
  ],
  "total": 60,
  "page": 1,
  "per_page": 20
}

Example

curl -X GET "http://localhost:8000/api/v1/widgets?category=content&page=1" \
  -H "Authorization: Bearer YOUR_TOKEN"

Create Custom Widget

Create a new custom widget for your organization.

Request

POST /api/v1/widgets
Authorization: Bearer {token}
Content-Type: application/json

{
  "name": "Custom Button",
  "slug": "custom-button",
  "description": "Custom styled button widget",
  "category": "interactive",
  "config_schema": {
    "text": {"type": "string", "label": "Button Text"},
    "variant": {
      "type": "string",
      "enum": ["primary", "secondary", "outline"],
      "default": "primary"
    },
    "size": {
      "type": "string",
      "enum": ["sm", "md", "lg"],
      "default": "md"
    }
  },
  "default_config": {
    "text": "Click Me",
    "variant": "primary",
    "size": "md"
  },
  "component_code": "export function CustomButton({ text, variant, size }) { ... }",
  "is_premium": false,
  "price": 0
}

Response

{
  "id": "uuid",
  "name": "Custom Button",
  "slug": "custom-button",
  "description": "Custom styled button widget",
  "category": "interactive",
  "config_schema": {...},
  "default_config": {...},
  "is_premium": false,
  "price": 0,
  "downloads": 0,
  "rating": 0,
  "created_at": "2024-01-01T00:00:00"
}

Update Widget

Update an existing widget (only for widgets you own).

Request

PUT /api/v1/widgets/{widget_id}
Authorization: Bearer {token}
Content-Type: application/json

{
  "name": "Updated Widget Name",
  "description": "Updated description",
  "config_schema": {...},
  "default_config": {...}
}

Delete Widget

Delete a widget (only for widgets you own).

Request

DELETE /api/v1/widgets/{widget_id}
Authorization: Bearer {token}

Response

{
  "message": "Widget deleted successfully"
}

TypeScript Client Example

import { apiClient } from '@/lib/api-client'

// List widgets
const getWidgets = async (category?: string, page = 1) => {
  const response = await apiClient.get('/api/widgets', {
    params: { category, page, per_page: 20 }
  })
  return response.data
}

// Get widget details
const getWidget = async (widgetId: string) => {
  const response = await apiClient.get(`/api/widgets/${widgetId}`)
  return response.data
}

// Create custom widget
const createWidget = async (widgetData: {
  name: string
  slug: string
  category: string
  config_schema: Record
  default_config: Record
}) => {
  const response = await apiClient.post('/api/widgets', widgetData)
  return response.data
}

// Update widget
const updateWidget = async (widgetId: string, updates: Partial) => {
  const response = await apiClient.put(`/api/widgets/${widgetId}`, updates)
  return response.data
}

// Delete widget
const deleteWidget = async (widgetId: string) => {
  const response = await apiClient.delete(`/api/widgets/${widgetId}`)
  return response.data
}

Widgets in the frontend follow this structure:

  isPreview?: boolean
  isSelected?: boolean
  isHovered?: boolean
  elementId?: string
  
  // Callbacks
  onChange?: (props: any) => void
  onStyleChange?: (style: any) => void
}

export function TextWidget({

  fontWeight,
  color,
  textAlign = 'left',
  isEditing,
  isPreview,
  isSelected,
  onChange,
  onStyleChange
}: WidgetProps) {
  // Widget implementation
  return (
    
      {text}
    
  )
}
