Apps API

Complete API reference for app management

Overview

The Apps API provides endpoints for creating, managing, and deploying applications in WebCraft. All endpoints require authentication.

Base URL

http://localhost:8000/api/v1/apps

List Apps

Get a paginated list of apps for the current user.

Request

GET /api/v1/apps
Authorization: Bearer {token}

Query Parameters:
- page: int (default: 1) - Page number
- per_page: int (default: 20, max: 100) - Items per page
- app_type: string (optional) - Filter by app type
- search: string (optional) - Search in names and descriptions

Response

{
  "apps": [
    {
      "id": "uuid",
      "name": "My App",
      "slug": "my-app",
      "description": "App description",
      "app_type": "website",
      "is_published": false,
      "custom_domain": null,
      "subdomain": null,
      "config": {},
      "theme_config": {},
      "seo_config": {},
      "created_at": "2024-01-01T00:00:00",
      "updated_at": "2024-01-01T00:00:00"
    }
  ],
  "total": 10,
  "page": 1,
  "per_page": 20
}

Example

curl -X GET "http://localhost:8000/api/v1/apps?page=1&per_page=20" \
  -H "Authorization: Bearer YOUR_TOKEN"

Create App

Create a new application.

Request

POST /api/v1/apps
Authorization: Bearer {token}
Content-Type: application/json

{
  "name": "My New App",
  "description": "App description",
  "app_type": "website",
  "template_id": "uuid" (optional),
  "config": {} (optional),
  "theme_config": {} (optional)
}

Response

{
  "id": "uuid",
  "name": "My New App",
  "slug": "my-new-app",
  "description": "App description",
  "app_type": "website",
  "is_published": false,
  "config": {},
  "theme_config": {},
  "seo_config": {},
  "created_at": "2024-01-01T00:00:00",
  "updated_at": "2024-01-01T00:00:00"
}

Example

curl -X POST "http://localhost:8000/api/v1/apps" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "My New App",
    "app_type": "website",
    "description": "A test application"
  }'

Get App

Get detailed information about a specific app.

Request

GET /api/v1/apps/{app_id}
Authorization: Bearer {token}

Response

{
  "id": "uuid",
  "name": "My App",
  "slug": "my-app",
  "description": "App description",
  "app_type": "website",
  "is_published": false,
  "custom_domain": null,
  "subdomain": null,
  "config": {
    "theme": "light",
    "features": ["feature1", "feature2"]
  },
  "theme_config": {
    "colors": {
      "primary": "#3b82f6",
      "secondary": "#6b7280"
    }
  },
  "seo_config": {
    "meta_title": "My App",
    "meta_description": "App description"
  },
  "created_at": "2024-01-01T00:00:00",
  "updated_at": "2024-01-01T00:00:00"
}

Update App

Update an existing app. Only provided fields will be updated.

Request

PUT /api/v1/apps/{app_id}
Authorization: Bearer {token}
Content-Type: application/json

{
  "name": "Updated Name" (optional),
  "description": "Updated description" (optional),
  "config": {} (optional),
  "theme_config": {} (optional),
  "seo_config": {} (optional)
}

Response

{
  "id": "uuid",
  "name": "Updated Name",
  "slug": "my-app",
  "updated_at": "2024-01-01T00:00:00",
  ...
}

Example

curl -X PUT "http://localhost:8000/api/v1/apps/{app_id}" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Updated Name",
    "config": {
      "new_setting": "value"
    }
  }'

Delete App

Delete an app. This is a soft delete (sets is_active to false).

Request

DELETE /api/v1/apps/{app_id}
Authorization: Bearer {token}

Response

{
  "message": "App deleted successfully"
}

Publish App

Publish an app to make it live.

Request

POST /api/v1/apps/{app_id}/publish
Authorization: Bearer {token}
Content-Type: application/json

{
  "custom_domain": "example.com" (optional),
  "subdomain": "my-app" (optional)
}

Response

{
  "message": "App published successfully",
  "url": "https://my-app.webcraft.dev",
  "custom_domain": null,
  "subdomain": "my-app"
}

Generate Preview

Generate a shareable preview link for an app.

Request

POST /api/v1/apps/{app_id}/preview
Authorization: Bearer {token}

Response

{
  "preview_token": "abc123...",
  "preview_url": "http://localhost:3000/preview/abc123...",
  "expires_at": "2024-01-02T00:00:00"
}

Error Responses

All endpoints may return these error responses:

401 Unauthorized

{
  "detail": "Could not validate credentials"
}

404 Not Found

{
  "detail": "App not found"
}

400 Bad Request

{
  "detail": "Validation error message"
}

500 Internal Server Error

{
  "detail": "An unexpected error occurred"
}

TypeScript Client Example

import { apiClient } from '@/lib/api-client'

// List apps
const getApps = async (page = 1, perPage = 20) => {
  const response = await apiClient.get('/api/apps', {
    params: { page, per_page: perPage }
  })
  return response.data
}

// Create app
const createApp = async (appData: {
  name: string
  app_type: string
  description?: string
}) => {
  const response = await apiClient.post('/api/apps', appData)
  return response.data
}

// Update app
const updateApp = async (appId: string, updates: Partial) => {
  const response = await apiClient.put(`/api/apps/${appId}`, updates)
  return response.data
}

// Delete app
const deleteApp = async (appId: string) => {
  const response = await apiClient.delete(`/api/apps/${appId}`)
  return response.data
}
