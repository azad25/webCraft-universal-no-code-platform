WebCraft Developer Documentation

Complete guide to building with WebCraft platform

Build Amazing No-Code Applications

WebCraft is a comprehensive, production-ready no-code platform for building websites, web apps, e-commerce stores, and business applications with powerful visual editing, automation, and AI integration.

Get Started View Architecture

Technology Stack

Backend

FastAPI, Python 3.11, PostgreSQL, Redis, Kafka

Frontend

Next.js 14, React 18, TypeScript, Tailwind CSS

Database

PostgreSQL 15, Redis 7, SQLAlchemy, Alembic

Infrastructure

Docker, Kubernetes, Nginx, AWS/GCP Ready

Visual Editor

Professional drag-and-drop editor with 60+ pre-built widgets and real-time preview.

AI Integration

AI-powered content generation, design suggestions, and SEO optimization.

Automation

Visual workflow builder with 100+ integrations and smart templates.

Multi-Platform

Generate mobile SDKs, export static sites, and deploy anywhere.

Collaboration

Real-time collaboration with WebSocket-powered live editing.

Module System

Extensible plugin architecture with dynamic module loading.
